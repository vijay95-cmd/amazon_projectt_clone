## 📌 Project Overview

This project recreates the core visual experience of an Amazon-style e-commerce website. It focuses on responsive frontend development, clean UI structure, product presentation, search interaction, category navigation, promotional sections, and a simple shopping-cart counter.

The implementation uses **HTML5 for structure, CSS3 for responsive styling, and vanilla JavaScript for client-side interactions**.

## 🔄 JavaScript Functionality

The JavaScript layer currently handles two main interactions:

```text
User clicks Add to Cart
        ↓
Cart count increases
        ↓
Button changes to "Added"
        ↓
Button becomes disabled
```

Search interaction:

```text
User enters search term
        ↓
Form submission is intercepted
        ↓
Search term is validated
        ↓
Search query is displayed
```
